# Link Rules

Use Obsidian wikilinks for internal links: `[[path|display name]]`.

## Topic Notes

```markdown
[[02-Cultivate/Topic Notes/Topic Name|Topic Name]]
```

Topic notes are stored in the configured topic notes folder. Use the path table from the system prompt instead of hard-coding defaults.

## Area Pages

```markdown
[[03-Connect/Area Name|Area Name]]
```

Area pages live in the configured domain pages folder.

## Project Links

```markdown
[[04-Create/Projects/Project Path/Project Overview|Project Name]]
```

Link to the project overview note, not only the project folder.

## Permanent Notes

```markdown
[[Note Title]] - relationship note
```

## Literature Notes

```markdown
[[02-Cultivate/Literature Notes/Book Title|Book Title]]
```

## Daily And Review Notes

```markdown
[[01-Capture/Daily Notes/YYYY-MM-DD|MM-DD]]
[[01-Capture/Weekly Reviews/YYYY-Www|Www Weekly Review]]
[[01-Capture/Monthly Reviews/YYYY-MM|MM Monthly Review]]
```
